# ПЕРЕКЛАД — перевод школьных материалов svenska → українська

Ученик или учитель загружает PDF / PPTX / DOCX / картинку и через несколько секунд
видит перевод прямо на сайте. Текст на картинках тоже переводится, фон сохраняется.
Учитель получает 5-значный код: ученики вводят его и открывают готовый перевод мгновенно.

## Как выложить на Vercel (один раз, ~10 минут)

1. Создайте на GitHub новый репозиторий и загрузите в него всё из этой папки
   (`index.html`, `package.json`, папку `api`).
2. На vercel.com: **Add New → Project → Import** этот репозиторий → **Deploy**.
   Ничего не настраивайте, фреймворк: «Other».
3. **Settings → Environment Variables**: добавьте
   `DEEPL_KEY` = ваш ключ DeepL (тот, что заканчивается на `:fx`).
4. **Storage → Create → Blob → Connect to project**. Vercel сам добавит переменную
   `BLOB_READ_WRITE_TOKEN`. Это нужно для кодов от учителя и кэша.
5. **Deployments → … → Redeploy**, чтобы переменные подхватились.

Готово. Без шага 4 сайт тоже работает, но без кодов: каждый переводит сам.

## Что где
- `index.html` — весь сайт (интерфейс + движок перевода, работает в браузере).
- `api/translate.js` — отправляет текст в DeepL (ключ спрятан на сервере).
- `api/doc.js` — коды и кэш (если файл уже переводили — отдаётся сразу).
- `api/upload.js` — разрешает браузеру сохранить страницы в Vercel Blob.

## Лимиты
- DeepL API Free: 500 000 символов в месяц (у вашего ключа видно 1 000 000).
  Обычная презентация — 3–8 тыс. символов. Одинаковые файлы переводятся один раз.
- Vercel Blob (бесплатно): несколько ГБ хранения. Презентация на 20 слайдов ≈ 10 МБ.
  Старые переводы можно удалять в Storage → Blob.

## Что не переводится
- Рукописный текст, очень мелкий или повёрнутый текст на картинках.
- Keynote (.key), старые .ppt/.doc — сохраните как PDF или .pptx.
